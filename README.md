# Sorting algorithm visualizations
A visualization of selected sorting algorithms to make understanding how different sorting techniques work easier to understand.

# Setup Instructions
1. Clone the repository
    ```
    git clone https://github.com/carmenjoekalda/Sorting-algorithm-visualizations.git
    ```
2. Navigate to the project folder
    ```
    cd Sorting-algorithm-visualizations
    ```
3. Check whether Python and pip are installed
    ```
    python --version # at least 3.13.x expected
    pip --version
    ```
4. Install pygame
    ```
    pip install pygame
    ```
5. Run the code
    ```
    python .\main.py # Windows
    python3 main.py # Linux & macOS
    ```
